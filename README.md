# Murchik Cakes Bot (Main Branch)

Telegram bot for managing Murchik Cakes orders, products, reviews and administration.

## Features

- Telegram Bot interface
- Product catalog
- Order management
- Admin panel
- Promo codes
- Reviews
- Multilanguage support
- Mini App integration support
- SQLite database
- Product photo management
- Order status system

## Stack

- Python
- python-telegram-bot
- FastAPI
- SQLite
- HTML/CSS/JavaScript

## Installation

```bash
git clone https://github.com/messerschmitt242-svg/Murchik_Cakes_Bot.git
cd Murchik_Cakes_Bot
pip install -r requirements.txt
```

## Environment

Create `.env` file:

```env
BOT_TOKEN=your_bot_token
ADMIN_IDS=123456789
WEBAPP_URL=https://your-domain.com
```

## Run

```bash
python bot.py
```

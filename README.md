# Murchik Cakes Bot 🍰

Telegram-бот для кондитерської **«У Мурчика»**.

Бот підтримує:
- каталог десертів
- кошик
- промокоди
- індивідуальні замовлення
- систему відгуків
- вибір мови
- багатомовність
- обране
- активні замовлення для адміністратора
- автоматичні переклади продуктів
- роботу через Railway

# 👑 Адмін-функціонал

## 📋 Активні замовлення
Тільки для адміністраторів.

Можливості:
- перегляд усіх замовлень
- зміна статусів
- окремі індивідуальні замовлення

Статуси:
1. Прийнято
2. Готується
3. Готове до видачі
4. Завершено

Коли замовлення переходить у статус:

```txt
Готове до видачі
```

користувач автоматично отримує:
- схему проходу
- інструкцію
- фото маршруту

## Telegram Channel Post Button

В проект добавлен скрипт для публикации поста в Telegram-канал с настоящей inline-кнопкой **🧁 Відкрити меню**.

Файл:

```bash
scripts/send_channel_post.py
```

Минимальные переменные в `.env`:

```env
BOT_TOKEN=your_bot_token
CHANNEL_ID=@your_channel_username
```

Запуск:

```bash
python scripts/send_channel_post.py
```

Перед запуском добавь бота администратором канала и дай право **Публикация сообщений**.

Подробная инструкция находится в файле:

```bash
CHANNEL_POST_INSTRUCTIONS.md
```

## Google Tasks для заказов

При создании заказа API может автоматически создавать задачу в Google Tasks. Это не блокирует оформление заказа: если Google не настроен или временно недоступен, заказ всё равно создаётся, а в логах будет `GOOGLE TASKS WARNING/ERROR`.

Нужные переменные Railway для сервиса API / Mini App:

```env
GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...
GOOGLE_REFRESH_TOKEN=...
GOOGLE_TASKLIST_ID=@default
```

`GOOGLE_TASKLIST_ID` можно не добавлять — тогда используется основной список задач `@default`.

Как получить `GOOGLE_REFRESH_TOKEN`:

1. В Google Cloud включить **Google Tasks API**.
2. Создать OAuth Client ID для Desktop app.
3. Локально задать `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET`.
4. Запустить:

```bash
python scripts/google_tasks_oauth.py
```

5. Открыть ссылку, разрешить доступ и вставить код в терминал.
6. Добавить полученный `GOOGLE_REFRESH_TOKEN` в Railway Variables сервиса API / Mini App.

Используется scope `https://www.googleapis.com/auth/tasks`.
